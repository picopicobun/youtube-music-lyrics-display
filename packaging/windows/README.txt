Waylyrics Windows Custom Edition
================================

This is a portable Windows build maintained by picopicobun and derived from
the open-source waylyrics/waylyrics project v0.4.0.

Quick start
-----------
1. Extract the entire ZIP file to a normal folder.
2. Double-click waylyrics.exe in the extracted folder root. You may also use
   launch-waylyrics.vbs; both start the app with the bundled GTK runtime.
3. Use the sandwich menu in the lyric window to adjust appearance, colors,
   font sizes, always-on-top, and click-through behavior.

Notes
-----
- Do not run the program directly inside the ZIP preview.
- Keep waylyrics.exe together with the bin, lib, share, and themes folders.
- The real application is bin\waylyrics-app.exe. Start it through the root
  waylyrics.exe so Windows can locate all bundled DLLs.
- Personal settings and lyric caches are created in the current Windows
  user's AppData folders. No maintainer settings or caches are included here.
- cool-glow.css is included as an optional theme preset.
